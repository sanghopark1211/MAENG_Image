# MAENG_Image_Sync — 초고속 카메라 조건 비교 앱

Phantom `.cine` 영상 두 개를 데스크톱 창에서 나란히 재생·비교.

## 실행
- **바탕화면의 `MAENG_Image_Sync` 바로가기** 더블클릭
  (또는 `MAENG_Image_Sync 실행.bat`)
- 기본 경로가 있으면 폴더 선택 없이 바로 시작

## 조건 버튼으로 영상 선택
각 패널 상단에서 버튼으로 고르면 파일이 자동으로 열림:
```
각도 : [0][15][30][45][60][75][90][105][120][135][150][165][180]
속도 : [1][30]  m/min
실험 : [1][2][3][4][5][6]     (없는 번호는 자동 비활성)
```
- 폴더 규칙 `각도_깊이_속도`, 파일 끝 `_N.cine` 을 자동 해석
- 규칙 밖 파일은 우측 '직접 선택 ▾' 목록에서

## 재생 조작
| 위치 | 기능 |
|---|---|
| 각 패널 | ▶/⏸ · −1 · +1 · 슬라이더 (완전 독립) |
| 하단 | ▶▶ 동시 재생 · ⏸ 동시 정지 · ±1프레임 · ⟲ 처음 |
| 옵션 | 속도(fps) · 루프 · 픽셀 선명 · 컬러 |
| 단축키 | Space=동시 재생/정지, ←→=1프레임, Home=처음 |

## 기술 메모
- 연속 제너레이터 판독: ~4 ms/frame (매회 오픈 46 ms 대비)
- 컬러 복원: Bayer(CFA=3) → WB+디모자이크+감마 LUT, ~13 ms/frame
- 바로가기 재생성: `바탕화면 바로가기 만들기.bat`
